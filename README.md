# StoryModeTrainer for GTA 5 Legacy (v1.0.3889.0)

Offline-only Story Mode trainer built for **GTA 5 Legacy** (`GTA5.exe 1.0.3889.0`) with **Script Hook V**, **ScriptHookVDotNet v3**, and **LemonUI**.

## Included & Verified Dependencies (12 Staged Files)
- **Script Hook V** (`v3889.0 / 1158.13`) — Legacy ASI Loader (`dinput8.dll`), `ScriptHookV.dll`, `args.txt` (`-nobattleye -noBE`). (`xinput1_4.dll` for Enhanced and sample `NativeTrainer.asi` are intentionally excluded.)
- **Engine Offline & Anti-Cheat Boot Config** — `commandline.txt` (`-scOfflineOnly` and `-nobattleye`), forcing `GTA5.exe` (`rage::sysParam`) and Rockstar Social Club into strict offline Story Mode at boot before scripts initialize.
- **Community Script Hook V .NET** (`v3.7.0-nightly.206`, built for `v1.0.3889.0`) — `ScriptHookVDotNet-Loader.asi`, `ScriptHookVDotNet.dll`, `ScriptHookVDotNet2.dll`, `ScriptHookVDotNet3.dll`, and hardened `ScriptHookVDotNet.ini` (`ConsoleKeyBinding=None`, `ReloadKeyBinding=None` so Online-lockout scripts cannot be paused or aborted from an in-game console).
- **LemonUI (SHVDN3)** (`v2.2.0.0`) — `scripts\LemonUI.SHVDN3.dll`.
- **StoryModeTrainer** (compiled `Release | x64`, `.NET Framework 4.8`) — `scripts\StoryModeTrainer.dll`, `scripts\StoryModeTrainer.ini` (`StoryModeTrainer.cs`, `TrainerConfig.cs`, `NoClipController.cs`, `HeistManager.cs`, `PlayerEnhancementsController.cs`, `VehiclePhysicsController.cs`, `OnlineAssetsController.cs`).

## Offline Story Mode <-> GTA Online Workflow

### Play Story Mode With Trainer (Offline)
1. **Option A (Fully Automated — Recommended)**: Double-click **`Launch-GTA5-Offline.bat`**:
   - Stages all 12 verified trainer files into GTA 5 Legacy (`commandline.txt` with `-scOfflineOnly -nobattleye`, `args.txt` with `-nobattleye -noBE`, and launcher `-nobattleye -scOfflineOnly`). *(If Rockstar Games Launcher periodically asks to refresh your offline ownership token, run `Manage-StoryTrainer.ps1 -Action LaunchOffline -WaitAndClean -OmitScOfflineOnly` once).*
   - Monitors your `GTA5.exe` session (with audible + visual compliance alerts if `GTA5_BE.exe` / `BEService` starts) and **automatically removes all mod files, logs, `args.txt`, and `commandline.txt`** when GTA 5 exits (even if interrupted), restoring `[VERIFIED VANILLA]`.
2. **Option B (Manual Toggle)**: Double-click **`1-Enable-OfflineMod.bat`** (imports all 12 files cleanly into your GTA 5 Legacy directory with SHA256 verification and transactional rollback on copy errors).
3. In **Rockstar Games Launcher -> Settings**, make sure **Enable BattlEye** is **unchecked**.
4. Launch GTA 5 Legacy Story Mode:
   - Press **`F3`** to open/close the trainer menu (`MenuToggleKey` in `StoryModeTrainer.ini`).
   - Press **`F9`** anytime to toggle **No-Clip** (`NoClipToggleKey` in `StoryModeTrainer.ini`).

### Return to GTA Online (Clean Vanilla)
1. Close GTA 5 completely.
2. If you didn't use `Launch-GTA5-Offline.bat`, double-click **`2-Disable-And-CleanForOnline.bat`** — automatically removes every ASI loader, Script Hook DLL, `args.txt`, `commandline.txt`, `scripts\` files, and runtime logs (`asiloader.log`, `ScriptHookV.log`, `ScriptHookVDotNet*.log`), then scans root for any leftover non-vanilla items (`mods\`, `plugins\`, `dxgi.dll`, `version.dll`, `*.asi`, `*.pdb`) and verifies clean vanilla state.
3. Re-check **Enable BattlEye** in Rockstar Games Launcher and launch GTA Online normally.

Use **`3-Check-ModStatus.bat`** anytime to check whether GTA 5 Legacy is currently **Clean Vanilla** or **Offline-Modded**, view read-only `BEService` service state, verify SHA256 file integrity, or view recent runtime logs.
